# TTTK1143 Program Design and Problem Solving - Tutorial 4 (Interface & UI)

Each folder has the original console program (`*App.java`) and a Swing GUI version (`*GUI.java`).

| Folder | Console | GUI |
|---|---|---|
| Q1_DataSet | DataSetApp | DataSetGUI |
| Q2_EdibleApp | EdibleApp | EdibleGUI |
| Q3_MobileDevice | MobileApp | MobileGUI |
| Q4_Price | PriceApp | PriceGUI |

## How to run (example: Q1)
```
cd Q1_DataSet
javac *.java
java DataSetGUI      # GUI
java DataSetApp      # console
```
Requires JDK 8 or newer.
